# Homebrew Tap for Kawu 🍿

Dépôt officiel Homebrew pour installer et mettre à jour **Kawu** sur macOS (Apple Silicon M1/M2/M3/M4 & Intel).

> Application de streaming pour regarder des films, séries et animés gratuit sans pub.

## Installation

```bash
brew install --cask ztvplusfr/tap/kawu
```

## Mise à jour

```bash
brew upgrade --cask kawu
```

## Désinstallation

```bash
brew uninstall --cask --zap kawu
```
